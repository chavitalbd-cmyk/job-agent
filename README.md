# סוכן המשרות · Job Agent

אתר אישי למעקב אחרי חיפוש עבודה: דשבורד, משרות עם ציון התאמה, קטגוריות, סדר עדיפויות, קורסים והגדרות.
הסריקה והמחקר נעשים על ידי סוכן Claude (בחשבון Claude של המשתמש), והאתר עצמו רץ לבד.

## איך זה בנוי
| חלק | מה זה | איפה |
|---|---|---|
| האתר | `index.html` + `store.js` | GitHub Pages (חינם) |
| מסד הנתונים | טבלה אחת `docs` עם הגנת שורות (RLS): כל משתמש רואה רק את שלו | Supabase (חינם) |
| הסוכן | משימה מתוזמנת ב-Claude שקוראת וכותבת דרך האתר | חשבון Claude של המשתמש |

אין בקוד שום מידע אישי. הפרופיל (שם, טלפון, ניסיון), המשרות וההגדרות נשמרים רק במסד הנתונים של המשתמש.

## התקנה (פעם אחת, כ-15 דקות)
1. **Supabase:** פותחים פרויקט חדש ב-[supabase.com](https://supabase.com).
2. **טבלה:** ב-SQL Editor מדביקים את `supabase/schema.sql` ולוחצים Run.
3. **משתמש:** ב-Authentication → Users → Add user יוצרים משתמש עם מייל וסיסמה (Auto Confirm).
   ב-Authentication → Sign In / Providers מכבים "Allow new users to sign up", כדי שאף אחד אחר לא יוכל להירשם.
4. **הגדרות:** ב-`config.js` ממלאים את Project URL ואת המפתח `anon public` (מ-Project Settings → API).
   **לעולם לא** את המפתח `service_role`.
5. **פרסום:** ב-GitHub → Settings → Pages → Deploy from branch → `main` / root.
6. **נתונים:** נכנסים לאתר, מתחברים, ובהגדרות → "ייבוא מגיבוי" טוענים את קובץ הגיבוי.

בלי שלבים 1–4 האתר עובד במצב ניסיון: הנתונים נשמרים רק בדפדפן.

## פרטיות
- המפתח הציבורי (anon) מופיע בכל דפדפן. זה תקין: ההגנה היא ההתחברות + Row Level Security.
- קבצי JSON (גיבויים) לא נכנסים ל-git (`.gitignore`).
- גיבוי: הגדרות → "הורדת גיבוי".
